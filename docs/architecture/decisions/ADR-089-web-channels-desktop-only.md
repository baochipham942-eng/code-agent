# ADR-089：Web 版通道账号管理保持仅桌面版

- 状态：**已接受（方案 A，2026-11-04，爸委托决策点 auto / engineering-policy 11-04）**
- 单号：N-CHANNELS-WEB-DISABLED-NO-EXPLAIN（用户侧说明，已合入 #2755）；N-CHANNELS-WEB-DISABLED-NO-EXPLAIN-FU1（本 ADR，只记录决策）

## 决策记录

Web 版设置里的「通道」只读：可以查看通道账号和状态；添加、连接/断开、编辑、删除只在桌面版 Agent Neo 里做。

- 方案 A：Web 版只读，管理留在桌面版（采纳）
- 方案 B：Web 版开放通道管理（暂不采纳）：需要先做鉴权加远程凭据写入的安全评估，必须另开新单，不在本决策范围

## 边界

1. Web 保留账号列表与状态的只读查看。
2. 五个置灰按钮（添加、空状态添加、连接/断开、编辑、删除）和区块说明都带同一条提示，指向桌面版：`ChannelsSettings.tsx` 的 `webOnlyNote`，文案 `channelsManageDesktopOnly`（中英文各一条）。
3. 不涉及任何鉴权或凭据写入改动。

## 后果

- Web 用户明确知道去哪里管理通道账号，不再面对无解释的置灰按钮。
- Web 端暂无远程管理通道的计划，除非新 ADR 改变。

## 回滚

需要新 ADR 推翻本决策，并先完成鉴权与远程凭据写入的安全评估；不能只靠去掉置灰实现。
