## P0 · 用户浏览共享个人 profile

### 根因

Surface 执行按 `conversationId + runId + agentId` 拼 `managedBrowserServiceKey` → `surface-<hash>` 独立 BrowserService；`ensureBinding` 一律 `profileMode: 'isolated'`。  
用户在浏览器 tab 里登录的态落在临时目录，关会话/重开 app 后**永不复用**——agent 隔离设计误伤用户浏览场景。

### 改动

| 点 | 行为 |
|----|------|
| `isUserBrowserSurfaceIdentity` | `agentId === SURFACE_USER_BROWSER_AGENT_ID`（既有 `user-browser-link`） |
| `managedBrowserServiceKey(user)` | → `BROWSER_POOL_DEFAULT_KEY`（`__default__`），acquire 走 null → 默认 BrowserService |
| `managedBrowserProfileModeForIdentity(user)` | → `persistent` → 目录 `managed-browser-profile`（`MANAGED_BROWSER_PERSISTENT_PROFILE_ID`） |
| agent 任务 | 仍 `surface-<hash>` + `isolated`（反向判据） |
| 同会话 user↔agent 共享物理窗 | 保留既有 sharing；新开 user 窗用个人档案；纯 agent 不读个人 key |
| release | 个人/default key **不**在 surface cleanup 时 release（登录态跨会话存活） |
| 孤儿目录 | `listOrphanManagedBrowserSurfaceProfileDirs` + `ORPHAN_MANAGED_BROWSER_SURFACE_PROFILE_POLICY.action = 'list-only'`（**不静默删**） |

主要文件：

- `src/host/services/surfaceExecution/ManagedBrowserProviderAdapter.ts`
- `src/host/services/infra/browserPool.ts`（export `BROWSER_POOL_DEFAULT_KEY`）
- `src/host/services/infra/browser/managedBrowserHelpers.ts`
- `src/host/services/infra/browserService.ts`（re-export 列表 API）

## P1 · Cookie 导入入口产品化

### 根因

ADR-041 导入链路已在（扫描 Chromium profile → Keychain 解密 → 写入 managed），但入口埋在 LocalOps `BrowserSurfaceContent` 深处，与 Codex「地址栏 ⋯ → 导入 Cookie」不对齐。

### 改动

- 浏览器面板地址栏 **⋯ 菜单**新增「导入 Cookie…」（`browser-agent-window-import-cookies`）
- 弹窗：扫描 → 选 profile → **确认导入**（IPC `userConfirmed: true` + 既有 one-time approval）
- 目标：默认 BrowserService **persistent** 个人档案（与 P0 同一目录）
- 失败人话：`humanizeBrowserCookieImportFailure`（Chrome 锁库 / 钥匙串拒绝等）
- i18n：`workbenchTabs` zh/en 域文件（`importCookies*` 键）
- `applyManagedBrowserCookies` 显式 `profileMode: 'persistent'`

主要文件：

- `src/renderer/components/workbench/BrowserAgentWindow.tsx`
- `src/renderer/services/browserCookieImportClient.ts`
- `src/renderer/utils/browserCookieImportMessages.ts`
- `src/renderer/i18n/workbenchTabs.ts`
- `src/host/services/infra/browser/managedBrowserCookieImport.ts`
