# Agent Neo v0.29.0

2026-07-31

- **实时语音可以自然轮流说话并把事情做完**：通话支持更稳定的插话、停顿与轮次判断，字幕会跟随当前发言生命周期收敛；可以选择麦克风、维护口述词表并配置不同 realtime provider。挂断后仍在执行的任务会回到会话任务卡，不会悄悄丢失。
- **任务工作区有了统一 Overview**：进入工作区就能看到当前任务进程、产物和下一步动作；右栏视图按会话记忆，状态读取失败会停止空等并给出安全重读入口。
- **项目协作开始跨设备共享**：云端项目空间和成员卡片元数据通过 Supabase 同步。你能看到其他成员的只读任务卡状态，正文、密钥和本地执行细节不会上传；归档、重试和重新同步都有明确收敛路径。
- **外部 CLI 引擎更容易接入**：Codex、Claude、Grok 等外部 Agent Engine 可以在设置中发现和配置，模型目录优先读取本机 CLI，失败时使用内置目录安全回退。
- **会话可以分叉和回退**：从任意锚点建立新分支或回退后继续，工作区、消息血缘和右栏状态保持一致；旧会话仍可追溯，不会被新分支覆盖。
- **审批、权限和团队任务更可靠**：目录授权、无人值守审批、专家权限、成员依赖和父任务停止统一进入可恢复的任务账本，重启或切换会话后不再只剩界面上的假状态。
- **技能与连接器安装更安全**：安装过程可以取消并回滚，敏感凭据使用安全引用保存；MCP 推荐 HTTP Streamable，旧 SSE 连接仍保留兼容提示。

## 升级说明

- 本版会自动使用新的 `collab_projects`、`project_members`、`project_invites` 与 `collab_cards` 云端表；生产 Supabase migration 已随发布前检查完成。
- 与 v0.28.1 的本地会话、项目、设置和 Durable Run 数据兼容，不需要手工迁移。
- 未登录时云协作保持关闭，本地工作区和任务卡继续照常使用。
