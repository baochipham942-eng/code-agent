# Agent Neo v0.29.2

2026-07-31

v0.29.2 是 Agent Neo 0.29 功能集的实际分发版本。v0.29.0 与 v0.29.1 都被正式发布闸门拒绝，没有产生可下载制品；本版在合并后的 main 上重新生成全部稳定性证据，并保留停止动作按当前运行精确收敛的修复。

- **实时语音可以自然轮流说话并把事情做完**：通话支持更稳定的插话、停顿与轮次判断，字幕会跟随当前发言生命周期收敛；可以选择麦克风、维护口述词表并配置不同 realtime provider。挂断后仍在执行的任务会回到会话任务卡。
- **任务工作区有了统一 Overview**：进入工作区就能看到当前任务进程、产物和下一步动作；右栏视图按会话记忆，状态读取失败会停止空等并给出安全重读入口。
- **项目协作开始跨设备共享**：云端项目空间和成员卡片元数据通过 Supabase 同步。其他成员的任务卡只暴露白名单元数据，正文、密钥和本地执行细节不会上传。
- **外部 CLI 引擎更容易接入**：Codex、Claude、Grok 等外部 Agent Engine 可以在设置中发现和配置，模型目录优先读取本机 CLI，失败时安全回退。
- **会话可以分叉和回退**：从任意锚点建立新分支或回退后继续，工作区、消息血缘和右栏状态保持一致。
- **停止动作按当前运行精确收敛**：旧的 Durable Run 终态不会再遮挡同一会话中新启动的任务；停止请求会命中当前 `runId`，并在界面与运行态清理完成后返回。

## 升级说明

- 生产 Supabase 已应用 `20260730000000` 与 `20260730001000` 两个 migration，既有 migration 记账未修改。
- 与 v0.28.1 的本地会话、项目、设置和 Durable Run 数据兼容，不需要手工迁移。
- 未登录时云协作保持关闭，本地工作区和任务卡继续照常使用。
