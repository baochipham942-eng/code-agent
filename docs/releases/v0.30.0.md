# Agent Neo v0.30.0

2026-08-03

这一版给 Neo 加了终端和浏览器现场，换了新的品牌标识，实时通话可以打断和调语速，浅色模式全面重做。

- **右栏多了一个终端，你和 Neo 共用它**：Neo 执行的命令你能实时看到，也能随时自己接手敲，不用再猜它到底跑了什么。
- **Neo 浏览网页时你能看见画面**：它开网页时侧栏会显示实时现场，做完留下最后一帧；聊天正文里的链接点开也落在这个侧栏，不会跳走。
- **换上了新的品牌标识**：全新的星芒标，空态页的星球可以拖着转，实时通话时状态栏的星球会跟着通话状态变化。
- **新增两套高对比主题**：深色浅色各一套，在设置里选，文字和背景的对比明显更强。
- **浅色模式全面重做**：状态标签、彩色徽标、按钮文字不再发虚，和深色模式的可读性拉平。
- **实时通话可以打断、能调语速、还能打字**：说话时可以直接打断它；语速分三档；通话中输入的文字会即时进入这通通话；用快捷键就能拨通；通话失败会在聊天里留下记录，不再悄无声息；通话用了多少额度能看到。
- **设计画布可以直接编排**：节点能拖动摆放，审批按改动大小分级，画布上的内容在审批期间被移走会给出提示。
- **任务工作区有了主路径视图**：进去就能看到当前任务走到哪一步、产出了什么、下一步能做什么。
- **启动更稳，页面打开更快**：修了开机时应用卡住不响应的问题；设置页首次打开明显更快，进本机操作页不再让整个应用停住。
- **一批日常问题修复**：中文文件名的图片能正常显示了；中文正文里的链接不再吞掉后面的标点和文字；新建会话后光标会回到输入框；通话字幕不再一段盖一段、来回跳；你在通话里说的话不会再丢。

## 升级说明

- 与 v0.29.2 的本地会话、项目、设置数据完全兼容，不需要手工迁移。
- 没有新增的数据库变更。
- 高对比主题在设置里选择后会跟随重启保留。
