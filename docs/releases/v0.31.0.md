# Agent Neo v0.31.0

2026-08-07

这一版把会话变成了指挥台——你说话的时候 Neo 不会再被自己手上的活占住；浏览器能带着你的登录态干活；侧栏终于能翻到和搜到所有历史会话。

- **会话不再被执行占用，随时能插话**：以前 Neo 在跑一件长活时，你打的字要排队等它结束；现在长活自动转到后台，你说的每一句都当场进入对话。想问「刚才那件怎么样了」，随时问，随时答。
- **一句话把活派到后台，还能中途改方向**：给活起个短名（「周报」「调研」），之后就用短名指挥——追加要求、改方向、叫停某一件，都不用先翻是哪个任务。几件活同时跑时说「停掉一个」，它会先问你停哪个，不会误伤。
- **通话里也能这么指挥**：说话派活、按短名问进度、中途转向、挂断后结果照样送达。任务卡在缺权限、缺信息这类障碍上会主动说一声卡在哪儿。
- **浏览器带着你的登录态干活**：可以把你自己浏览器里的 Cookie 导进来，Neo 就能用你已登录的身份去看需要登录才能看的页面。侧栏浏览器还多了地址栏，能自己敲网址回车跳转。
- **历史会话终于搜得到、翻得到**：搜索接上了全文索引，中文两字词也能搜；侧栏列表支持分页，不再只能看到最近那一批。
- **专家团「用这个团」修好了**：以前点「用这个团」经常找不到出厂团队，三处入口全是失联的，被弹窗遮着看不出来。现在预选直接进输入框，跟「请 TA 来」一样的交互。
- **输入框一整轮打磨**：删光文字后光标和提示语会正常回来；空输入框能看见光标；pin 的资料在文字里显示成内联标签，光标不会跑进标签里；会话、空间、草稿三处的上下文互不串扰。
- **资料带进新会话更快，也看得见了**：带材料开新会话会立刻显示对应标签，不再要等；有材料时不再摆通用模板卡。
- **概览页重做成四个模块**：任务、待办、上下文、产物各归各位，一眼看清这个任务走到哪了。
- **产物卡和工具行的表达统一了**：产物卡跟着缩略图收窄不再通栏；工具执行行的措辞和对齐统一，失败时不再一边说「失败」一边用肯定语气描述动作。
- **测试包可以多个并存**：内部测试用的 Dev 包现在能同时装好几个、各自独立数据，互不打架。
- **一批日常问题修复**：退出全屏后侧栏 logo 残留；引擎选择器检测中没有反馈、没有工作目录时无法现场选；工作目录多处真相不一致；产物卡动作条三处失效。

## 升级说明

- 与 v0.30.0 的本地会话、项目、设置数据完全兼容，不需要手工迁移。
- 会话搜索首次使用会在后台建立全文索引，历史会话多时可能需要片刻。
- 「等前台跑完再作为下一轮发出」的旧排队行为已退役——现在消息一律当场进入对话，长活自动转后台。
