# Agent Neo v0.32.0

2026-08-11

这一版主要在稳定性上下功夫：刚打开就能用、自动更新更稳、操作失败不再默默无声，遇到问题还能一键导出诊断包。

- **刚打开 App 就能用，第一条消息不再偶尔失败**：以前启动后立刻发消息，偶尔会碰上一次失败要重发；现在会等服务真正能接单再发出，启动后马上就能对话。首轮响应也更快了一点。
- **自动更新更稳，不再偶尔卡住或留下残留**：修好了更新过程中偶发的卡顿和数据库残留问题，Windows 上更新时会先好好收尾再重启。
- **操作失败不再默默无声**：以前有些操作在后台悄悄失败、你完全看不到；现在它们会明确告诉你结果卡在哪儿。
- **遇到问题能一键导出诊断包**：出问题时可以直接导出一份诊断信息，方便快速定位，不用再手动翻日志。
- **对话中能直接查看更多内容**：前台放开了一批只读操作——能看、不改动，不用先切到专门的面板。
- **Windows 上运行更稳定**：修好了个别会导致卡死或进程残留的问题，长时间运行更省心。

## 升级说明

- 与 v0.31.0 的本地会话、项目、设置数据完全兼容，不需要手工迁移。
- 本版以稳定性修复为主，没有改变既有的使用方式。
