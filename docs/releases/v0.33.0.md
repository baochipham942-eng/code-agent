# Agent Neo v0.33.0

2026-08-19

这一版把注意力放在三件事上：长对话里的阅读体验、语音通话的自然度，以及"它到底替我做了什么"的可追溯性。同时接入了更多模型和联网搜索源。

- **长对话往上翻不再乱跳**：以前对话攒到几百轮之后，往上翻历史时画面会突然跳一大截，搜索跳转过去也常常看不到目标那条，流式输出时还会跟不回底部。这三个问题这一版一起修好了。
- **语音通话不再抢话**：你话说到一半停顿时，它不会再抢着接。挂断意图识别得更准，通话中断线重连后待确认的操作也能接上，不用重来。
- **能看到它做过什么**：新增会话检查器，能查看每一轮里它实际调用了哪些能力、按什么顺序、结果如何；通话有了审计时间线。程序意外退出后，这些记录也不会丢。
- **联网搜索可以自己配**：接入了智谱和 MiniMax 两个搜索源，密钥在设置页填。每轮对话都能单独开关联网，不想让它上网查的时候可以关掉。
- **更多模型可用，回答更快更省**：新增对 DeepSeek 等模型新接口的支持，模型能力（是否支持联网、深度思考等）改为自动识别，不用手工配置。同时给每轮对话瘦身了约 4500 个词元的固定开销，长对话的成本和延迟都会下降。
- **审批更可靠**：修好了几处需要你确认的操作可能被静默放过的情况——现在没人确认就一律不执行。被拒绝时也会说清楚是谁拒的、为什么。
- **阅读体验细节**：中英文混排的间距和字重重新调过；代码块和图表在深色模式下不再出现黑块；侧边栏滚动条不再挤压正文。

## 升级说明

- 与 v0.32.0 的本地会话、项目、设置数据完全兼容，不需要手工迁移。
- 如果你之前手工配置过模型的能力开关，本版会自动识别，原有配置仍然有效。
