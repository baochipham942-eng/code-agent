Before · 当前实现

首次使用先遇到技术配置

  1. 必须先注册开放平台并准备 API Key。
  2. 一屏选择大量 Provider，新用户难以判断。
  3. 连接后自动保存一个模型，用户没有明确选择。
After · 产品判断

复用已有订阅，完成两次确认就能对话

  1. 点击一个已登录且验证可用的官方产品，直接进入模型页。
  2. 确认该来源下的模型后，直接进入 Neo 当前会话页。

模型展示规则

Neo 本体与外部 CLI 位于同一执行引擎层级。选择 Neo 后展示 Provider 模型并提供“去设置”；选择外部引擎后按其模型能力展示。

图标来源

正式图标由受信任的引擎 Manifest 引用随适配器发布的本地资产；缺失或校验失败时使用统一终端图标。当前稿中的线性图标仅用于占位。

演示状态

用空状态验证“推荐安装 / 指定路径 / 改用 API Key”三条恢复路径。

边界

发现本机应用不等于可用。正式实现必须分别验证安装、登录、协议兼容与模型目录；Neo 不读取或复制官方客户端凭证。
