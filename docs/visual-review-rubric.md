# VLM 视觉走查席固定 rubric

这份清单只用于生成供人复核的候选草稿。每项取值为 `PASS`（图中有正向证据）、`RED`（图中有可见反证）或 `NA`（当前画面不适用/证据不足）。标红只建议人打开对应图，不接 CI，也不拦 PR。

权威机器版位于 `scripts/visual-review/rubric.json`；条目均来自 2026-08-27 图廊 14 项判定表中人工实际使用过的视觉判据。

| ID | 判据 | 金标来源 |
| --- | --- | --- |
| VR-01 | 审批卡风险信息可读、危险徽标单一，拒绝/取消位于最右主操作位；不要求按钮必须实心着色。 | #1 DECIDE-COMPACT |
| VR-02 | 提问卡与输入框共存；推荐徽标最多一个，未操作前不伪装成已选中。 | #2 DECIDE-NOREPLACE |
| VR-03 | 决策卡收起后保留“待你决定”及数量。 | #3 DECIDE-KEYS |
| VR-04 | “已编辑 N 个文件”/增删行数与运行指示或“请求批准”同屏，说明待审批写入被伪装成完成，必须标红。 | #4 TURNDIFF-PENDING |
| VR-05 | 长等待中的审批/确认卡保持可见可操作，不显示超时或自动决定。 | #5 APPROVAL-NOTIMEOUT / WAITCARD |
| VR-06 | 主时间线状态和右栏运行明细使用面向人的措辞，不泄漏原始工具名、内部标识、协议串；侧栏测试会话名不评分。 | #6 STATUSWORD、#7 HUMANPIPE |
| VR-07 | 主时间线、决策/错误卡和右栏运行明细的关键文案完整可读；侧栏导航标题不评分。 | #7 HUMANPIPE |
| VR-08 | 中断态有灰色原因句和继续/放弃入口，同屏不残留“等待模型回响”。 | #8 REPLAY / ONESIGNAL |
| VR-09 | 普通完成轮不无依据显示“自称完成/完成有据”；开发者态可见日志内容。 | #9 OUTCOME-STAMP |
| VR-10 | 主轮结束或停止全部后，专家/成员不残留“正在整理任务…”等运行态。 | #10 EXPERT-STALESTATUS |
| VR-11 | 无活跃决策/错误卡的新/空会话右栏，或展示专家/日志的工作台里，“任务”必须常驻；文件预览不属于该工作台。 | #11 RIGHTPANEL-TABS |
| VR-12 | 429 等错误只保留一个清晰文字信号，不叠加重复“目标已中止”大卡。 | #12 ERRORCARD-PLAIN |
| VR-13 | 无页面横向滚动、内容越界或裁切；步骤进度条不算溢出；浅色弹层轻阴影、无硬黑边，主题边界可辨。 | #13 THEME-LAYOUT |

席外项：#14 的 webServer / renderer `ERROR` 计数必须由日志门判断，单张截图不评分。
