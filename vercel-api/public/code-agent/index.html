怎么工作

从一句话，到一个能交付的结果

你给方向，Neo 负责拆解、执行、核验。长任务持续推进，不用你盯着。

  1. 01INPUT

    理解目标

    接收你的想法、资料和边界，明确这次要交出什么。

  2. 02PLAN

    形成计划

    拆出步骤，选择合适的模型、技能和工作面。

  3. 03EXECUTE

    跨工作面推进

    在浏览器、桌面与终端里执行，进度随时可见。

  4. 04DELIVER

    核验并交付

    文件、变更和过程记录一起留下，拿到就能继续用。
